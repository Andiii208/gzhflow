# 阶段① 素材先行（Material-First）

> 目标：动笔之前把足够的真实素材备齐。**这是整条流水线去 AI 味的最大杠杆。**
> AI 味不是写出来的，是没东西可写时硬写出来的。

## 顺序变了：先收集，再提问

以前这一步只有一套提问模板，等于把素材全押在"当场问用户"上。
用户不想答，阶段① 就塌，后面全塌。

现在分三段，**提问从默认动作降级为兜底动作**：

```
①a 收集   →  ①b 筛选  →  ①c 补问
先翻存量      按硬度排序      只问还缺的
```

### ①a 收集（按顺序翻这些地方）

1. `assets/inbox.md` —— 输入收件箱。日常"记一笔"攒下来的东西，**先查这里**。
   这个文件被 gitignore，clone 下来没有是正常的，直接跳到第 2 条
2. `references/seed-inbox-2026-10-12.md` —— 首批种子，用前先让用户逐条确认过
3. 用户本轮对话里已经说过的话——刚才聊到的内容就是现成素材
4. 用户明确说"多去网上搜集例子" → 主动检索，**标出来源给用户核对**后再动笔

### ①b 筛选（按锚点硬度排）

| 硬度 | 类型 | 怎么用 |
|---|---|---|
| 硬 | 具体时间 / 地点 / 画面 / 亲身经历 | 全文围着它转，不另起炉灶 |
| 中 | 用户转述的别人的事、读到的材料 | 当例证，不能当"我"的经历 |
| 软 | 只有观点 / 主题词 | 当论点，但撑不起一篇，见 ①c |

### ①c 补问（只问缺口，且只问一轮）

- 缺什么问什么，不要上来就抛 3-5 个问题
- **只问一轮。** 用户拒答或说"你自己深入思考"，立刻转下面的备选路径，别反复追问消耗耐心

## 意图三问（动笔前必答）

- 写给谁看？
- 想让他读完产生什么感觉？
- 为什么是今天写这篇？

三个问题答不上来 → 先不写，回到用户确认。

## 思辨深挖（素材不足时的备选路径）

用户拒答 / 说「你自己深入思考」时：

- 输出「这个主题背后在发生什么」的新洞察（机制层：如"判断负担 / 责任转移"这类）
- 给用户拍板，认可后再动笔
- **禁止用语言技巧填充空白**（排比 / 升华 / 正反论证）——那是 AI 味

## 输出物

素材锚点清单：

```
主题：
写作意图：写给谁 / 什么感觉 / 为什么今天
素材锚点：1. 2. 3. ...（用户原话 / 场景 / 细节，注明来自 inbox 还是本轮对话）
待补充：无 / 以下未确认...
范文锚参考：assets/voice-samples/ 里与本话题相关的段落（交给阶段②）
风格路由：见 config/styles.yaml 匹配结果（交给阶段②）
```

## 防坑

- ❌ 预设场景细节（"宿舍灯关了 / 明早八点有课"）——用户可能根本不在那个处境
- ❌ 替读者（「你」）预设行为（"你也会发一条朋友圈"）——同样是编造
- ❌ 方向确认当成素材确认——用户回答了「读者定位 / 标题」不等于给了「具体时间 / 地点 / 画面」
- ❌ 把观点当素材用——观点是论点，画面才是锚点。只有论点没有画面，写出来必空
- ⚠️ 素材类型不能跨阶段迁移：初中阶段的例子只能用在那一段，别挪到"长大后"
