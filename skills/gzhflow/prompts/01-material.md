# 阶段① 素材先行（Material-First）

> 目标：在动笔之前，从用户那里挖出足够真实的素材颗粒。**这是整个工作流去 AI 味的最大杠杆**——AI 味不是写出来的，是没东西可写时硬写出来的。

## 核心纪律

1. **收到主题先别动笔**。问 3-5 个针对性问题，挖出真实颗粒再写。
2. 用户的**每一句话、每一个场景都是锚点**，全文围着锚点转，不另起炉灶。
3. 只给主题没给素材 → **先坦白缺什么，不硬写**。硬写出来的必是 AI 味。
4. **素材提问只问一轮**，用户拒答后立即转入思辨深挖（见下），不要反复追问消耗耐心。

## 提问模板（按需选取 3-5 个）

- 这事发生在什么时候？（时间颗粒）
- 当时什么感觉？（情绪颗粒）
- 有没有一个具体的画面？（场景颗粒）
- 这件事里有没有一个只有你知道的细节？
- 你希望读者读完是什么感受？

## 意图三问（动笔前必答）

- 写给谁看？
- 想让他读完产生什么感觉？
- 为什么是今天写这篇？

三个问题答不上来 → 先不写，回到用户确认。

## 素材类型判断

| 用户给了什么 | 怎么用 |
|---|---|
| 具体时间/地点/画面/亲身经历 | 这些是**锚点**，全文围着转 |
| 只有观点/主题词 | 缺素材 → 坦白缺什么，问一轮，拒答则转思辨深挖 |
| 说「多去网上搜集例子」 | 主动 web_search 补充真实例子，**标出来源给用户核对**后再动笔 |
| 分阶段的素材（如初中/长大后） | 例子只能用在对应阶段，**禁止跨阶段迁移** |

## 思辨深挖（素材不足时的备选路径）

用户拒答/说「你自己深入思考」时：

- 输出「这个主题背后在发生什么」的新洞察（机制层：如"判断负担/责任转移"这类）
- 给用户拍板，认可后再动笔
- 禁止用语言技巧填充空白（排比/升华/正反论证）——那是 AI 味

## 输出物

素材锚点清单：

```
主题：
写作意图：写给谁 / 什么感觉 / 为什么今天
素材锚点：1. 2. 3. ...（用户原话/场景/细节）
待补充：无 / 以下未确认...
风格路由：见 config/styles.yaml 匹配结果（交给阶段②）
```

## 防坑

- ❌ 预设场景细节（"宿舍灯关了/明早八点有课"）——用户可能根本不在那个处境。任何地点/时间/季节/身份细节先问
- ❌ 替读者（「你」）预设行为（"你也会发一条朋友圈"）——同样是编造
- ❌ 方向确认当成素材确认——用户回答了「读者定位/标题」不等于给了「具体时间/地点/画面」。**素材颗粒（时间/地点/画面/亲历）一个都没有，素材先行就没走完**
