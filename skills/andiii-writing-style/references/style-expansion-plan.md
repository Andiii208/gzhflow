# 多平台文风扩展参考

> Andiii碎碎念写作风格库的采集来源不限于微信公众号，还应从知乎、小红书等平台汲取优质的个人叙事风格。

## 知乎

| 方法 | 可用性 | 说明 |
|:----|:------:|------|
| RSSHub (`rsshub.app`) | ✅ 免费 | 可为知乎回答/专栏生成RSS源，web_extract可读XML |
| 用户发链接 | ✅ 最佳 | 用户刷到好的回答，复制链接发来即可分析 |
| web_extract 直读 | ❌ 被挡 | 知乎反爬严，无代理读不到正文 |
| 浏览器直读 | ❌ 被挡 | 同样被反爬拦截 |

**搜索关键词建议：**
- "你有什么道理后悔没有早点知道" 高赞
- "大学应该明白哪些道理" 高赞
- "成长过程中最大的遗憾" 高赞 回答
- "你在哪一瞬间觉得心很累" 高赞 感性 叙事

## 小红书

| 方法 | 可用性 | 说明 |
|:----|:------:|------|
| `xhs-toolkit` MCP | ⏳ 待装 | 开源小红书MCP工具，可接入Hermes |
| 用户发链接 | ✅ 最佳 | 最直接的方式 |

**搜索风格方向：**
- plog日记式博主（图文结合的叙事）
- "碎碎念"风格笔记（短段落、真实感）
- 大学生活/日常感悟类笔记

## 执行流程

用户发链接 → 浏览器/web_extract尝试读取 → 成功则10维分析 → 分析卡存入 project → 精华提炼入 andiii-writing-style SKILL.md
