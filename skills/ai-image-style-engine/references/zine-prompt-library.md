# Andiii Zine 弹药库（5 主题模板）

> 2026-08-04 补。用法：选主题 → 填 `{槽位}` → 换 P2 隐喻 → 过质检门。模板是灵感起点不是限制，允许跨风格混搭。
> 词汇提示：zine 系纸感词（aged paper/旧纸/牛皮纸）+ 纹理词（risograph/xerox/halftone/scan noise/ink bleed/letterpress/grain/mottling/影印/拼贴）均已入质检门词表。

## 主题索引

| 编号 | 主题 | 默认 wash | 适用文风 |

| Z01 | 记忆/旧物 | pale yellow wash | 深度文艺/新世相 |

## Z01 记忆/旧物

```text
16:9 横构图，全幅旧纸底（aged paper texture），80%留白，risograph grain + xerox softness + scan noise，视觉簇构图自由。安全区：画面顶部与底部边缘各保留纯纸色留白。
{旧物意象：一张泛黄的照片/一只旧手表/一封信的残角}，撕边旧照片质感，影印柔化，油墨渗开，轻微套印错位
微文本碎片字母散落，低对比灰墨，muted palette with a pale yellow wash，纸纤维
怀旧、记忆感、档案感，避免高饱和，避免光泽质感
```
