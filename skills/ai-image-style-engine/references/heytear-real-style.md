# 真实喜茶风（拙趣儿童简笔画）纯文生图配方

> 2026-08-05 用户两次否掉旧"喜茶风"（宣纸水墨新中式）后验证定稿。权威源：GitHub `Hchen1218/heytea-style`（图生图向，风格四层+参考图）+ 喜茶 2025「拙趣」视觉（Design360 分析：拙感手写体、圆钝简笔画、破除网格、松弛不刻意）。

## 风格核心（四层）

1. **插画主体**（文生图版；图生图版=真实物件摄影锚点）：均匀黑色描边、简洁扁平、圆润简约，**不要照片质感**
2. **大面积白底留白**：暖白/米白底，物件占画面 25-45%，其余留白
3. **粗黑断笔简笔画小人**（micro worker）：笔触粗糙断续、线条僵硬有断笔和坏连接、没有眼睛没有嘴巴、四肢是僵硬的短线段、尺寸极小（约物件高度的 8-18%）
4. **歪扭手写字**（可选，仅带字版）：拙感黑体、笔画不均、竖直错落两列；**公众号配图默认无文字**，文案由排版承载

## 四段式 prompt 模板（文生图，已验证 15 张全过）

```
喜茶风插画，儿童简笔画涂鸦风格。干净的暖白色背景，大面积留白。
画面中下部[插画主体：黑色描边简洁扁平 + 一句细节]。
旁边一个极小的粗黑线简笔画小人，笔触粗糙断续、线条僵硬有断笔，小人[动作]，没有眼睛没有嘴巴。
整体拙趣、松弛、留白，像儿童绘本插画配随手涂鸦。
没有任何文字、没有logo、没有水印。
避免照片质感，避免摄影，避免3d渲染，避免渐变，避免光滑矢量，避免贴纸可爱风，避免密集装饰，避免真实人脸，避免水墨国画，避免书法，避免网红奶茶店风
```

封面加安全区句：`画面顶部与底部边缘各保留纯白留白，便于安全裁切。`

## 出图/交付规范

- 比例：封面 16:9 → 中心裁 2.35:1；分享 1:1；内文 16:9（900×506）
- 批量前**先出一张试水图给用户确认方向**（用户明确否过三版：水墨做旧、现代极简白杯茶烟、摄影质感——拙趣简笔画插画版通过试水，但**整篇 13 张交付后仍被否**："不好不好不好，还是不好看"）
- **喜茶风即使修正后仍高风险**：2026-08-05 歌单文最终连拙趣插画整批都否掉，用户从风格库改选**潦草手账（andiii-sketchy-style）交付成功**。歌单/音乐/散文类题材，潦草手账（铅笔抖线/马克笔点缀/胶带/涂改）是已验证的稳妥路线；喜茶风再启用时务必先出试水图、小批量、准备好 fallback
- 用户强调"**不要真实摄影质感，就要插画**"——文生图禁止照片锚点、禁止摄影词
- 质检门：白底黑线小人无宣纸/水墨/茶渍词，旧纸感词校验不适用；用本模板自带"避免"清单兜底
