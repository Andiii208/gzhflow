# gzhflow 工作台 · 设计逻辑 v4「编辑台」

> 2026-11-09 修订。v3 把结构从卡片堆改成了连续版面，但仍有两处根子问题：
> 一是自己造了一套青瓷绿 + 琥珀的配色，跟 DSH 的浅色/深色主题打架；
> 二是页面骨架仍靠「小标签 + 小按钮 + 细线」堆信息，标题、动作、读数没有明确的主次。
> v4 只做设计，不换功能：颜色全部交还给宿主，版面重排成一份能读的工作纸。

---

## 1. v3 复盘

| 症状 | 根因 |
|---|---|
| 颜色突兀 | 自建设计令牌（`#0f7a6c` 青瓷绿、`#9a5b06` 琥珀），浅色像另一个 App，深色里更明显 |
| 一屏没有主角 | 标题、阶段、指标、动作字号都在 12–19px，视觉重量接近 |
| 处处是框 | 每个区块都是边框 + 圆角 + 内边距的小盒子，区块之间的留白被框线切碎 |
| 同一件事说四遍 | 顶部导航「阶段」+ 阶段页本地页签 + 进度轨 + 底部进度说明 |
| 阅读页不像页面 | 阶段页把全文铺到 1100px 宽，一行 60+ 个汉字，读起来像后台表单 |
| 空态占半屏 | 体检、轨迹、配图都用「大块空白 + 一行灰字」表示没有数据 |

## 2. v4 的六条规则

1. **色只来自宿主**。页面/表面/描边/文字全部取 `--dsw-alias-*`，强调色就是宿主的墨色
   （`--dsw-alias-brand-primary`），状态色从 `--dsw-alias-state-*` 派生。插件里不出现
   任何十六进制颜色，深浅色由 DSH 主题自动切换。
2. **一页一个页头**。所有页面共用同一套页头：眉标（11px）→ 标题（30 / 23px 宋体）→
   一句话说明（13px）→ 元信息（12px）；右侧只放「这件事到哪了」。
3. **读用宋体，操作用无衬线**。稿纸标题/正文用 Songti SC 系；按钮、标签、表格用宿主
   无衬线；数字与路径用等宽 + tabular-nums。字号阶收敛为 30 / 23 / 21 / 16.5 / 13.5 / 12 / 11。
4. **一条进度轨**。七阶段只留顶部 rail（当前段实心、已完成段半透明），删掉阶段页的
   第二层页签和重复指标条；阶段页的「本阶段产物 x/y」挪到页头右侧。
5. **阅读优先**。总览与阶段②③都改成左稿纸、右体检的两栏；稿纸限宽 820px，
   正文 16.5px / 2.05 行高，左对齐、按块分段。
6. **控件只有三种**：墨色实心（主操作）、细描边（次要）、无边框 ghost（辅助）。
   陶土色只留给「当前」「WARN」「选中」，不再有大面积品牌色块。

## 3. 结构

```
页头         眉标 / 标题 / 说明 / 元信息                     右侧：进度、状态、动作
进度轨       素材 ── 写作 ── 去味 ── 配图 ── 排版 ── 发布 ── 复盘
指标条       正文 | 句数 | 阅读 | 体检 | 产物 | 轨迹（竖线分隔，无卡片）
命令条       [通过 / 退回 / 续跑]                        [体检][新写]  写操作就绪？
────────────────────────────────────────────────────────────
总览         左：稿纸（4 段预览）+ 读感（句长 / 节奏）   右：AI 味体检 + 产物
阶段②③      左：全文稿纸                              右：AI 味体检
阶段①④⑤⑥⑦  本阶段产物 / 配图清单 / 手机预览 + 排版控制 / 发布清单 / 复盘两栏
轨迹         概况指标 + 事件分桶柱 + 构成带 + 工具 Top → 筛选 → 时间线
产物         左：产物预览   右：按阶段分组（大小条 + 修改时间）
库           页头 + 页签 → inbox 三栏看板 → 记一笔
绑定         页头 + 当前绑定 → 候选会话列表
```

## 4. 视觉规格

| 项 | 规格 |
|---|---|
| 页面底色 | `--dsw-alias-bg-base` |
| 稿纸 / 卡片 | `--dsw-alias-bg-layer-1` + 1px `--dsw-alias-border-l2` + `--dsw-shadow-lv1` |
| 分隔线 | `border-l2` 62%（soft）；区块之间 24px 留白 |
| 字号 | 30 页标题 / 23 子页标题 / 21 稿纸标题 / 16.5 稿纸正文 / 13.5 UI / 12 元信息 / 11 眉标 |
| 数字 | 等宽 + `tabular-nums`，指标值 21px / 600 |
| 圆角 | 控件 8 / 稿纸 14 / 弹层 16 / 胶囊 999 |
| 间距 | 4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 |
| 动效 | 160ms `cubic-bezier(.2,0,0,1)`；`prefers-reduced-motion` 全关 |
| 焦点 | `:focus-visible` 2px 墨色环 |
| 宽度 | 内容 1200px；断点用容器查询 1120 / 860（跟面板走，不跟视口走） |
