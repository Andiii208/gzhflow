# gzhflow 工作台 · 设计逻辑 v3

> 2026-11-09 修订。v2 把「卡片做得更统一」，但页面逻辑仍然是错的：**七个同权圆角盒子堆在一起，四张 KPI 卡平权竞争，一屏没有主角**。v3 推翻这一版结构，改成「一个连续版面 + 一个主角 + 一条命令」。

---

## 1. v2 为什么还是丑

| 症状 | 根因 |
|---|---|
| 整页像一堆盒子 | 每个区块都套了卡片（边框 + 阴影 + 圆角），视觉上没有层级，只有噪音 |
| 四张 KPI 卡一模一样 | 把「四个数」当成四个并列的容器，而不是一行信息 |
| 标题不是最显眼的 | 最大的数字是「2,228 字」（次要信息），文章标题只有 20px |
| 进度被说了四遍 | 圆圈编号 + 阶段名 + 产物小圆点 + 底部进度条，四重表达同一件事 |
| 动作散在各处 | 体检在卡片里、排版在阶段页、通过在另一张横幅里，找不到「现在该按哪个」 |
| 深浅色只是换了色值 | 没有重新分配语义：整页 90% 是灰的，状态色几乎看不见 |

---

## 2. v3 的六条规则

1. **不用卡片堆页面**。区块之间用留白 + 一条 1px hairline 分隔；只有真正需要框的东西（稿纸、按钮、输入框、手机预览）才有边框和圆角。
2. **一屏一个主角**。文章标题 28px / 650 字重 / -0.006em；其余文字一律退到 13px 以下；数字用 tabular-nums。
3. **一个进度表达**。七阶段只用一条 7 段 rail（当前段实心、已完成段半透明），去掉编号圆圈、产物圆点和进度条。
4. **一条命令条**。所有动作集中在标题下方一行：通过 / 退回 / 续跑 / 体检 / 新写。右侧只放一句「写操作是否就绪」。
5. **左文右控**。总览页左边是稿纸（正文 + 文本度量），右边是控制台（体检 + 产物）。稿件是主角，控制信息靠边。
6. **颜色只表达状态**。青瓷绿 = 进行中 / 可交互；琥珀 = 待办 / WARN；玫红 = 失败 / FAIL；靛蓝 = 工具；紫 = 决策。没有装饰性色块。

## 3. 结构对照

### 3.1 总览

```
报头        阶段小标 → 文章标题(28px) → 一行 meta（模式/开写/目标/绑定/产物）      右上 2/7
进度轨      ①──②──③──④──⑤──⑥──⑦   （可点，当前段实心）
指标条      正文 | 句数 | 阅读 | 体检 | 产物 | 轨迹      （一行，竖线分隔，取代四张卡）
命令条      [通过][退回][续跑] [体检][新写]                                  写操作就绪？
─────────────────────────────────────────────────────────────
左：正文稿纸（标题 + 元信息 + 正文 + 读全文）      右：AI 味体检（仪表 + 规则分布 + 明细）
    文本度量（句长直方图 + 段落节奏条）                产物清单（密集列表）
```

### 3.2 其它页

| 页 | 结构 |
|---|---|
| 阶段 | 阶段标题 + 七段页签 → 指标条 → 本阶段正文（稿纸 / 配图网格 / 手机预览 / 发布清单 / 复盘两栏） |
| 轨迹 | 指标条 → 节奏折线 + 构成条形 + 工具调用 Top → 筛选 → 时间线（等宽时间列 + 类型色点） |
| 产物 | 左：预览（稿纸 / 手机 / JSON）　右：产出时间线 + 按阶段分组的密集列表（带大小条） |
| 库 | 页签（inbox / voice / lessons / 手改记录 / 历史）→ 选中项内容 → 记一笔输入行 |
| 绑定 | 当前绑定信息（键值两栏）+ 候选会话密集列表 |

## 4. 视觉规格

| 项 | 规格 |
|---|---|
| 页面底色 | `--dsw-alias-bg-base`；稿纸 `--dsw-alias-bg-layer-1` + 1px hairline + `--dsw-shadow-lv1` |
| 分隔线 | `color-mix(--dsw-alias-border-l1 62%)`，区块之间 1px |
| 字号阶 | 28（标题）/ 19（指标数值）/ 17（稿纸标题）/ 13（正文与面板）/ 12（元信息）/ 11（标签、大写） |
| 间距 | 4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 |
| 圆角 | 控件 6–7px、稿纸 12px、胶囊 999px；页面级不再出现大圆角 |
| 字体 | 正文 `--dsw-font-family`；数字与路径 `--ds-font-family-code` + tabular-nums |
| 动效 | 只保留 120–200ms 的颜色/位移过渡；`prefers-reduced-motion` 全关 |
| 焦点 | `:focus-visible` 用 2px accent 环 |

---

## 5. 响应式

工作台是 DSH 的主面板，面板宽度 ≠ 视口宽度，所以断点用 **CSS 容器查询**（`@container`）跟面板走：

- ≤ 1120px：两栏并排 → 单栏，标题降到 25px；
- ≤ 820px：报头竖排、指标条换行、手机预览占满。
