# 输入收件箱（inbox）

这个文件是整条流水线的水源。**阶段① 启动时先读它，命中就直接用，没命中才向用户提问。**

## 怎么往里喂

对任意 Agent 说一句「**记一笔：……**」，Agent 负责追加到下面的「未处理」区。
不需要打开文件、不需要记格式。一句话、一个画面、一段读到的材料加一句你的反应，都算。

## 分三区，用完往下挪

- **未处理**：刚记的，还没被任何一篇文章用过
- **已用**：被哪篇文章用了（写文章标题），方便回溯
- **沉淀**：出现过两次以上的念头，说明是真关心，可升级为选题候选
