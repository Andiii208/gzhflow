# 范文锚（voice-samples）

这里放**你自己写的、满意**的文字段落。写作阶段（②）动笔前按话题读 1~3 段。

## 先说清楚：范文不等于"发表过的旧稿"

这一点以前写错过，害得人以为必须攒够几篇已发布的文章才能开始。
不是的。范文锚的门槛只有一条：

> **是你自己写的，而且你现在回头看还认可。**

跟发没发表过、写在哪儿、写给谁，都没关系。已发布的文章只是其中一种来源。

## 为什么是它而不是规则文档

三条独立证据指向同一结论：

- ACL 2025（arXiv:2503.04369）：只加「请自然一点」这类约束提示词不可靠，GPT-4 在
  specified prompt 下翻译腔错误率反而上升；而 polishing 自修订能把它从 43% 降到 25%
- 百度千帆实测：试过一堆方法后，「直接给它一个案例让它模仿」影响最大。样本 1~3 个就够，
  每段约 300 字时 AI 理解最精准
- 密歇根大学 / Stony Brook / 哥伦比亚的联合研究：仅用 in-context prompting 时，MFA 科班
  专家仍能看出人写的更好；但模型读到作者真实文本后，专家在风格匹配与整体质量两项上
  常转而偏好 AI 的文本

也就是说：**规则是「关于风格的知识」，范文才是「风格本身」。** 上面的 voice.md 讲道理，
这里的段落给手感，两者一起用。

## 没有旧稿怎么办：按这个顺序试

### 路径 A：翻存量（最优先，通常 10 分钟就有收获）

在这些地方找你亲手写过、且现在看还认可的长段：

- 手机备忘录、笔记 App
- 微信/QQ 里你发给别人的长消息（认真解释一件事的那种，不是闲聊）
- 朋友圈长文、QQ 日志、博客旧文
- 课程报告、实验总结里你自己写的分析部分
- **你让 AI 写完后自己大改过的稿子**——改动超过一半的地方，那就是你写的
- 你跟 AI 的对话里，你亲自打的大段话（解释观点、吐槽、讲清楚一个道理的那种）

找到 3 段、每段 300 字左右就够了。不完整也行，一个片段就是一个锚。

### 路径 B：写自述（兜底，半小时）

一段都翻不到，就用大白话回答三个问题，让 Agent 整理成 `00-自述.md`：

1. 你自己写过、现在回头看还满意的一句话是什么？一句就够
2. 你最讨厌哪种句式、哪个词？（有明确厌恶清单的人反而好办——
   「冗长啰嗦」「AI 味」「套话」都是可用的负向锚）
3. 你希望读者读完用什么词形容你的文字？

这不是范文，是**负向锚 + 审美锚**，比什么都没有强，而且能直接并进 `assets/voice.md`。

### 路径 C：等系统自己长出来（必然发生，不用特意做）

第 1 篇按完整流程发出去之后，从里面切最满意的一段，那就是第一批正式样本。
飞轮转起来之后，范文锚会自己变厚。

### 路径 D：借味（只做临时参考，别进这个目录）

余光中〈怎样改进英式中文？〉、思果《翻译研究》的检查清单，治翻译腔很好用。
但那是**借味**——拿余光中当范文，出来就像余光中，不像你。而且别人的文章
有版权问题，不能进公开仓库。只在 ③b 冷读时临时参考，不落地到 `voice-samples/`。

## 硬约束

1. **只能是你自己写的。** 别人的文章有版权问题；而且借来的味道是别人的
2. 每段约 300 字。太短学不到节奏，太长会稀释特征
3. 文件名按话题起，方便阶段② 检索，如 `01-宿舍夜谈.md`、`02-期末周.md`

## 没有范文不阻塞第一篇

`assets/voice.md` 已经是完整可用的风格档案（定位、节奏、标题、声音红线都有），
阶段② 靠它完全能开写。范文锚是**提升项，不是阻塞项**——先发第一篇，样本会自己长出来。
