# 范文锚（voice-samples）

这里放**你自己写的、满意**的旧稿段落。写作阶段（②）动笔前按话题读 1~3 段。

## 为什么是它而不是规则文档

三条独立证据指向同一结论：

- ACL 2025（arXiv:2503.04369）：只加「请自然一点」这类约束提示词不可靠，GPT-4 在
  specified prompt 下翻译腔错误率反而上升；而 polishing 自修订能把它从 43% 降到 25%
- 百度千帆实测：试过一堆方法后，「直接给它一个案例让它模仿」影响最大。样本 1~3 个就够，
  每段约 300 字时 AI 理解最精准
- 密歇根大学 / Stony Brook / 哥伦比亚的联合研究：仅用 in-context prompting 时，MFA 科班
  专家仍能看出人写的更好；但模型读到作者真实文本后，专家在风格匹配与整体质量两项上
  常转而偏好 AI 的文本

也就是说：**规则是「关于风格的知识」，范文才是「风格本身」。** 上面的 voice.md 讲道理，
这里的段落给手感，两者一起用。

## 硬约束

1. **只能是你自己写的稿子。** 别人的文章有版权问题；而且借来的味道是别人的——
   你拿余光中当范文，出来就像余光中，不像你
2. 每段约 300 字。太短学不到节奏，太长会稀释特征
3. 文件名按话题起，方便阶段② 检索，如 `01-宿舍夜谈.md`、`02-期末周.md`
