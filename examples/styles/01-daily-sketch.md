# 示例文风：日常白描（Daily Sketch）

> 这是**去个人化示例**——展示一个完整文风档案怎么写。直接复制到 `config/styles.yaml` 即可用，或作为模板改造成你自己的风格。
> 风格原型：从「日常小事/白描叙事」类公众号的共性提炼，已剥离任何具体账号信息。

## 风格名

`daily-sketch`

## 一句话描述

从具体场景切入，把思考过程当戏写，极短段落，真诚自嘲，适合日常小事、个人记录、生活观察。

## 适用话题

- 今天遇到/看到/闻到/想到一件小事
- 日常记录、个人经历、生活观察
- 写给自己、纯感受、不想共鸣

## 风格特征

### 标题
- 公式：为什么 + 日常现象；或 好事物 + 反向词
- 示例：
  - 《为什么每次期末周我都想收拾房间》
  - 《自习室的代价》
- 原则：≤20 字、制造认知缺口、不用震惊体

### 开头
- 方式：场景切入 + 个人困惑（不铺陈背景，直接进入一个具体瞬间）
- 示例：「昨天晚上失眠到三点，不是因为考试，是因为想到一个奇怪的问题——」

### 人称与视角
- 人称：「我」贯穿始终（需用户提供亲历素材；无素材时转「你/我们」）

### 段落节奏
- 2-5 行短段落，关键句独立成段
- 写完一段经历 → 空一行 → 一句金句单独成段
- 节奏标记词：「不对。」「等等。」「哦。」「原来如此。」（每篇 ≤2 处）

### 内容结构
- 一件事 → 一个感悟；或 几件事 → 一个主题
- 经典推进：「开场（遇到X）→ 困惑/不服 → 推理/折腾 → 打脸/认输 → 豁达」

### 金句
- 密度：全文 1-2 句
- 结构：排比 + 反转（「三个都是……唯有……。」）

### 结尾
- 平淡收束，不做结论，留给读者回味
- 示例：「后来我想，**这大概就是……吧**。」

### 配图
- 无图或 1 张手机摄影

## 参考源

- 从「把思考当戏写」的日常叙事类公众号共性提炼（不保留具体账号与文章）

## 自检

1. 这句是我真的想说的，还是为了「好看」写的？
2. 如果朋友读到，会觉得这是「我」写的吗？
3. 有没有一句话能让读者停下来想一会儿？
4. 我有没有在编造不属于用户的经历？（「我」开头每句都能证实吗？）
