# examples/image-engines — 配图风格引擎示例说明

本目录放配图风格引擎定义（`.yaml`，纯 YAML 四件套：色彩/纹理/排版/规避）。配图阶段按文风路由到对应引擎时，读该文件编译 prompt。

## 已注册引擎

| 文件 | 风格 | 适用文风 |
|---|---|---|
| 01-watercolor.yaml | 手绘水彩（暖米纸+低饱和晕染+笔触） | 诗意/散文/情感向 |
| 02-zine.yaml | Zine 拼贴（档案感/破碎拼贴/印刷颗粒） | 深度/文艺/读书笔记 |
| 03-sketchy.yaml | 潦草手账（铅笔线条/胶带/涂改） | 日常随感/小事记录 |
| 04-minimal.yaml | 石墨极简（全灰阶/留白理性） | 科技/专业观点/高端 |
| 05-heytear.yaml | 喜茶拙趣（手作感/暖调/轻快） | 生活/美食/轻松话题 |
| 06-crt.yaml | 黑白针管笔（细线/疏密对比/无彩） | 文艺/深度/黑白摄影感 |

> 风格路由：配图阶段先读 `references/image-style-routing.md` 的「图源三问」分轨（真实图 vs AI 图），AI 轨再按文风选引擎。所有引擎遵循「风格是参考不是限制」——允许跨风格借用/混搭，质检门（质感/雷区底线）仍生效。

## 01-watercolor.yaml 使用要点（配图阶段照此执行）

- 晕染色以水彩湿画法晕染、色带、洗淡照片区存在——**禁止平涂色块**（晕染区合计 10%-25%，单色块 <5%）
- 转译规则：抽象主题 → 一个可画的具体意象（孤独 → 一扇半开的窗，窗帘被风吹起一角）
- 布局多样性：连续多张时避免雷同（换锚点类型）
- 封面 16:9 附加安全区约束句：`构图安全区：画面顶部与底部边缘各保留纯纸色留白（无文字无主体），便于安全裁切`

想自定义引擎：复制 `engine-template.md` 为 `<你的引擎名>.yaml`，逐项填写，然后在配图阶段按文风路由选用。
