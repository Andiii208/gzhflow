# 去 AI 味手册（De-AI Craft）

> 阶段③ 的核心方法论。AI 味 = 太均匀 + 太正确 + 太完整。
> 一致的声音，反直觉地比完美中立散文更不统计平均——所以读起来像人。

## 〇、输入端杠杆（最高优先级）

**AI 味不是写出来的，是没东西可写时硬写出来的。** 只要输入是「主题」而不是「素材」，AI 就只能用语言技巧填充空白——排比、升华、金句、正反论证。这些就是 AI 味。

输出端工具（删模式/模仿风格）都是给嫌疑人找罪证，删狠了文章会坏。真正的杠杆在输入端：

1. **素材先行**：收到主题先别动笔，问 3-5 个针对性问题，挖出真实颗粒再写
2. **写作意图三问**：写给谁看？想让他读完产生什么感觉？为什么是今天写这篇？答不上来就不写
3. **完备性 ≠ 人味**：AI 什么都写到，人是有选择的——有的地方写三行，有的地方就三个字，有的地方故意不说

## 一、AI 味三层模型

| 层 | 表现 | 管它的工具 |
|---|---|---|
| 语言层 | 三连排比/强行升华/「值得注意的是」/em dash/同义词轮换/翻案腔/冒号滥用/黑话 | `scripts/ai_flavor_score.py` 机器门 |
| 结构层 | 每段「观点→例证→升华」、首尾填充句、段落长短均匀、每段都有金句 | 结构层手术（下节） |
| 声音层 | 一切都太正确：无立场/无矛盾/无毛刺/无私人性/无意外 | 声音层（下下节） |

## 二、结构层手术刀

1. **删首尾测试**：删掉某段第一句和最后一句，如果段落还通顺——那两句就是填充，删
2. **删「只为引出下一句」的句子**：一句只承担「铺垫」功能 → 删掉它，把下一句改写成独立句
3. **拆「完美段落」**：观点+例证+收束齐全 → 拆开：观点单独成段，例证跟上，**不要每段都收束**——有的段就该戛然而止
4. **去掉「每段一金句」**：连续 3 段都以金句收尾 = 强 AI 味。金句是稀有品，全文 1-2 句足够
5. **不均匀化**：长短句交替（一句 8 字 + 一句 30 字）；段落长度故意错落
6. **改结构不改词汇**：换句子顺序、换开头方式、换节奏，比换同义词有效 10 倍
7. **删过渡词**：「所以/但是/然而/更重要的是」开头句，直接切入内容

## 三、声音层（AI 味的根本）

1. **立场贯穿**：全文选一个态度（这件事让人惦记 / 它被低估了），让态度决定选词和强调点——拒绝「完美中立」。⚠️ 立场 ≠ 负面表达：用「惦记/珍惜/想不通但放不下」这类暖立场，不用「烦/讨厌」（公众号忌讳负面表达）
2. **承认矛盾**：写「既…又…」的真实复杂（「惦记，但又不敢靠近」），不要一路正确到底。矛盾也走暖调
3. **允许不完美**：偶尔的口语、突然的细节、一句没说完的话、一个跑题的括号
4. **具体 > 抽象**：「孤独」→「周日傍晚空荡的食堂二楼」；「压力」→「手机还剩 3% 电量的时候」（用用户给的素材，不编造）
5. **少一点「不过/但是」**：AI 习惯先肯定再否定。直接说，别每次都转折
6. **结尾不升华**：AI 最爱结尾拔高。真实的人结尾是「就到这里」或一个具体的小细节

## 四、人称适配（公众号代笔关键）

代笔写作时，**禁止「我」叙事**（除非用户给了具体亲身经历素材）。统一用「你/我们」：

| AI 第一人称本能 | 公众号适配（第二人称） |
|---|---|
| 我搞不清这是好是坏 | 你说不清这是好是坏 / 我们谁也说不好 |
| 我总会绕回那个画面 | 你总会绕回那个画面 |
| 真正戳我的是 | 真正戳你的是 |
| 我也干过这种事： | 你也干过这种事： |

原则：保留反 AI 味操作（删模式），替换人称（「我」→「你/我们」）。立场/矛盾/毛刺都可以用「你/我们」表达。

## 五、操作流程

```text
1. 初稿 → 机器门扫描（语言层清理）
2. 结构层手术：删首尾填充 / 删引子句 / 拆完美段落 / 去金句堆叠 / 不均匀化
3. 声音层检查：立场在吗？矛盾在吗？毛刺在吗？结尾升华了吗（删）？
4. 人称检查：全文「你/我们」，无「我」叙事（引用/对话原文除外）
5. 机器门复检：硬禁令清零
6. 二次自问：哪句最像 AI 写的？—— 删/改它
7. 交付全文给用户审阅
```

## 六、机器质检门（ai_flavor_score.py）

与配图质检门（check_image_prompt.py）对称——**硬禁令机器可查，不再全靠 agent 自觉**。

```bash
python scripts/ai_flavor_score.py <稿件.md>
python scripts/ai_flavor_score.py --text "直接传文本"
```

- **硬禁令（FAIL，必须清零）**：中文/英文冒号（引出人物原话除外）、破折号（`—`/`——`/`–`）、硬停词（说白了/说穿了/先说结论）、黑话（赋能/抓手/闭环/底层逻辑/全链路/组合拳等）、模型路标（值得注意的是/需要指出的是/更微妙的是）、翻案句（不是…而是/并非…而是/不在于…而在于/与其说…不如说/表面…其实/看似…实则）
- **WARN 项（人工判断）**：引语冒号、语境黑话（沉淀/颗粒度/对齐/方法论等，本义准就留）、翻案腔变形（以为…其实/回头才发现/真正…的是）、三连以上同构排比、抒情词（安放/抵达/微光/滚烫 ≥2）、名词化句式、连词密度、句长变异系数、短段连击、重复开头词、隐喻簇

**与碎碎念体的边界**：脚本禁的是**模型腔修辞动作**，不禁风格——第二人称、无主句、口语零结构、金句 ≤1 全部兼容。改违禁句时先找回它原本想说的事实，用普通句子说，不要找另一种漂亮句式替换。

## 七、人味自检（替代「查AI味」思路）

1. 文章里有没有至少一个「只有用户知道的细节」？没有 → 回去补素材，不是删句子
2. 找出全文最顺、最工整的三句话——那是 AI 味浓度最高的地方，优先处理
3. 完备性检查：有没有哪段可以只讲一半、甚至故意不说？
4. 无成本检查：漂亮句子超过 2 句 → 删到只剩最要紧的
