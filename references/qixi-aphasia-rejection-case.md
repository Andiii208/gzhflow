# 案例 5：七夕与失语症（2026-08-19，6 版 + 全自动收尾）

> 本文件是 style-rejection-cases.md 案例库的第 5 个案例（因 curator 写保护机制限制，以独立 reference 记录；文风被否时与案例库同读）。核心教训已浓缩在文末「已验证教训」，可并入 SKILL.md 写作陷阱。

**主题**：《七夕与失语症》类散文。用户素材：① 语文从小到大引以为傲、一直觉得能写出很好的作文，但中考高考都差一点运气没展现出来；② 大学学理工科、与文学告别、刷无意义社交媒体 → 语言匮乏，想写写不下去、聊不深入；③ 想象中的大学自由开放，实际忙碌无意义、没机会认识人。**用户明确要求：标题就叫《七夕与失语症》，但不要写二者关系，类散文风格**（原话：「我说了不要你强制的写七夕和失语的关系…不要写他们之间的关系，不然显得我这个人像个性压抑」）。

## 已验证教训（浓缩版，可并入 SKILL.md 写作陷阱）

1. **双概念标题禁止硬连关系**：标题「X与Y」≠ 论证关系。用户要的是并置。前 5 版都在找逻辑桥全被否，第 6 版两章并置零说明通过。判断规则：标题含「X与Y」时先问——用户要的是论证关系，还是并置两个意象？
2. **节日语境自怜姿态三雷区**：舔狗（想认识人没机会）、性压抑（把节日和个人欲望挂钩）、小丑（热闹跟我没关系）。修复=节日章节完全去「我」，只做客观白描（传说/节日本义/现象级描述），「我」只在个人章节出现。判断规则：写节日前自问——这句会让「我」显得在渴望、在酸、在围观吗？是就删。
3. **短句轰炸+突兀转折=AI 味**：类散文要长句绵延（逗号串 3-5 个分句）与短句交替、自然思绪过渡（「晚上静下来，忽然想起一件事。自己好像已经很久，没有认真写过什么东西了。」），不一句一行、不空行硬拼。与「过于自然=刻意AI味」互补：短句过多和口语毛刺过多都是 AI 味，句子主体写干净书面、允许长句绵延。
4. **编造细节/自创比喻逐句点名**：「两小时能写完」「排着队出来」「被碎片塞得满满」「多数没营养」全是用户素材外的自创。细节比喻只从用户原话长出来；写感受不写评价（「每天花很多时间刷社交媒体，刷完也说不上看了些什么」✓，「刷的多数没什么营养」✗）。
5. **社交平台点评腔=自媒体模板**：「晒花的晒礼物的，一年一年都是差不多的热闹」被否。写节日不要「刷了一圈朋友圈」式平台观察+编辑点评；改写节日本义（七夕原是乞巧节，古时女孩向织女乞巧求心灵手巧，「巧字，已经没人提了」），安静且有思辨口子。
6. **数据引用在散文可被整段删**：中青报「词穷」调查一句话带过+标来源仍被要求删掉；删则删，不辩解「这是你要的素材」。
7. **散文思辨落地**：通过版思辨=「那几乎是我唯一能证明自己的场合，两次都没赶上。所以'我写得还不错'这件事，说到底，只是我自己一直这么觉得」「想写，又不知道写给谁看。高中写作文，好歹有个老师批，有个分数，有个人告诉你写得好不好」「别人的表达，看多了，慢慢就觉得自己不用说了」。思辨织进体验，不贴解说词。
8. **用户说「走完全部流程」= 全自动授权**：不再逐环节确认，自动跑完配图→排版→推送→验证，交付时汇报全流程清单+草稿箱 API 拉回验证（不能只信 media_id），脚本见 draft-verification.md。

## 获认可的最终结构（可复用）

节日白描（无我）→ 节日本义/巧字（留思辨口子）→ 自然过渡（晚上静下来想起一件事）→ 个人失语史（骄傲→没被证明→理工科告别→写不出）→ 大学围城（认识的人不能说少，话都在表面）→ 极简三句收（「话还在，只是说不好了」）。
