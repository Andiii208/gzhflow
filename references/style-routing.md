# 风格路由表

> 写作时根据话题自动匹配最合适的风格。

## 自动匹配规则

优先级从上到下。用户的话题命中最上面的规则就使用对应的风格。

| 优先级 | 话题关键词 | 匹配风格 | 核心切换 | 参考来源 |
|:------:|-----------|---------|---------|:--------:|
| 1 | 小事、日常、刚才、今天遇到、看到、闻到、听到、发现 | **槽边往事风** | 从具体场景切入→感悟，娓娓道来 | A 组 |
| 2 | 很美、安静、黄昏、夜晚、宇宙、星空、风、云、海、诗、月光、雾 | **MorningRocks 风** | 诗歌感 + 极简 + 留白 + 审美包装 | A 组 |
| 3 | 难过、烦、累、不想说话、迷茫、孤独、疲惫、算了 | **酒鬼诗人风** | 隐喻 + 意象 + 允许脆弱 + 短促收尾 | A 组 |
| 4 | 想跟你说、你知道吗、你有没有、我也是、我猜你、你是不是也 | **海听风** | 亲密对话感 + 第二人称 + 结尾抛回读者 | A 组 |
| 5 | 困惑、选择、毕业、考研、工作、未来、到底该不该、怎么办 | **WhatYouNeed 风** | 群体共鸣 + 开放性问题 + 不替读者做决定 | B 组 |
| 6 | 读书、电影、看到一篇文章、想起一句话、里面说 | **不止读书风** | 从读到感：书是引子，感受才是正文 | C 组 |
| 7 | 记录、今天、日常、普通的一天、流水账 | **杂乱无章风** | 轻量 + 治愈 + 极简 + 短段落大留白 | B 组 |
| 8 | 以上都不匹配 | **融合风格** | 综合 A 组成果，默认使用 | A 组综合 |

## 不同风格的表现差异

| 写作维度 | 槽边往事风 | MorningRocks 风 | 酒鬼诗人风 | 海听风 |
|---------|-----------|----------------|-----------|-------|
| **标题** | 名词短语（"一碗面""下雨天"） | 极简（"暮色""星"） | 意象（"杯子空了""今晚的雨"） | 问句（"你也有过吗"） |
| **开头** | 场景切入（时间+地点+动作） | 画面描述（自然景色/光影） | 感受+隐喻（"像被什么东西压着"） | 第二人称提问（"你有没有……"） |
| **段落** | 3-5行短段，关键句单句成段 | 极短段（1-3行），大量留白 | 随性，长短交替，无规律 | 中等段落（4-6行），节奏均匀 |
| **句子** | 短句为主（15-30字），偶尔长句破节奏 | 短句，有诗句感，节奏舒缓 | 长短随意，跟着情绪走 | 中长句为主，娓娓道来 |
| **结尾** | 平淡收束，不做结论 | 留白，一句话收住 | 一句短促收住 | 问题抛给读者 |
| **"你"频率** | 低 | 低 | 中 | 高 |
| **"我"频率** | 高 | 中 | 高 | 高 |
| **自我暴露** | 高（分享生活细节和感受） | 中（观察多于表达） | 高（直接表达脆弱） | 高（分享个人故事） |
| **配图** | 手机摄影/无配图 | 自然风景/抽象/天文摄影 | 暗调/氛围感 | 生活场景/日常 |
| **选题来源** | 个人经历（极小的事） | 观察+阅读+感受 | 个人情绪 | 个人经历+他人故事 |
| **读者距离** | 近 | 中（保持一定距离） | 很近 | 很近 |

## 用户手动指定的语法

用户可以在指令中直接指定风格：

```
写一篇公众号文章，用槽边往事那种风格，主题：今天在食堂
写一篇像海听那样说话的文章，主题：最近有点累
写一篇MorningRocks风格的，主题：今晚的月亮
```

支持的风格名称：槽边往事、MorningRocks、海听、酒鬼诗人、WhatYouNeed、不止读书、杂乱无章
