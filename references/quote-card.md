# 金句卡（quote-card）

> 2026-10-12 建（v5B B4）。④ 配图的**可选输出**：思辨/观点文里抽 1–3 句做成可转发的小卡。
> 品味底线吸收自 `lijigang/ljg-skills` 的 `ljg-card`（MIT，7493⭐），
> 但**把它的技术路线换掉了**——它用 HTML/CSS + 无头浏览器截图（Node/Playwright），
> 违反 gzhflow 的「Run 路径零依赖」；本仓库改成**直接生图**（GPT-image-2 文字渲染够强）。

## 一、什么时候做，什么时候不做

- **按需追加，不进默认 4 张**：正文配图默认 1 封面 + 2–3 内文。金句卡是附加产出，
  想加就加进 manifest（`role: "quote-card"`），走同一套预算账目
- **只有思辨/观点文才值得做**：叙事、散文向文章里的"漂亮句子"做成卡会显得自我感动
- 一篇文章最多 3 张。挑的是**读者会想转发的判断句**，不是最工整的句子
- **判据（借 ljg）**：这张卡删掉之后，读者对文章的理解不变吗？不变就别做

## 二、文字怎么上卡（这是最关键的一条）

GPT-image-2 中文渲染强，但**不是无损**。错字是卡面上最刺眼的缺陷，必须分档：

| 句长 | 路线 |
|---|---|
| ≤20 字（含标点） | 直接生图，文字写进 prompt |
| 21–40 字 | **拆成 2 张**，每张 ≤20 字；或改成更短的判断句 |
| >40 字 | **不作卡**。退回排版层的金句块（`skills/gzh-design/references/common-components.md`） |

**生成后必须逐字核对卡面文字**——AI 生字会错字、多字、漏字。错字 → 重生，
**最多 2 次**；仍错 → 弃用这张卡，改走排版层。不要为了保住一张卡反复烧钱。

## 三、版式规范

按 **1080px 宽**校字号，不要拿网页字号直接套（这是 ljg 踩过的坑）：

| 项 | 值 |
|---|---|
| 画布 | 1080 × auto（长卡）或 1080 × 1080（方卡，分享用） |
| 底色 | 纯白 `#FFFFFF`（或主题的 `bg`） |
| 正文色 | 深中性黑 `#171717`，**不用纯黑 `#000000`** |
| 正文字号 | ≥40px（1080 宽下等效手机约 14.4px） |
| 行高 | 1.9 |
| 有效文字宽 | 约 896px（左右各留 ~92px） |
| 段距 | 36px；章节间距明显大于段距 |
| 署名/来源 | 30px，正文之后，克制的中性灰 |

## 四、七条品味底线（吸收 ljg，按本仓库改造）

1. **判断先于装饰**：版面服务那句话，不是那句话给版面当素材
2. **视觉必须有工作**：卡上若配图，要能回答「它让读者看见了哪句文字看不见的东西」。
   答不出 → 纯字卡，不要图。**纯字卡是完全合法的成品**
3. **版式不要平均**：禁止把文字机械切成三等分、四等分，或一排相同的卡
4. **字与颜色**：主色要有角色，不把五六种高饱和色平均分给模块；
   **禁渐变、厚阴影、玻璃拟态、发光边框**——这几样正是本仓库的硬雷区
5. **中文与事实**：不编数字、引语、机构、人名、来源。
   结尾停在内容自身的最后一句，之后**只留署名与来源**——不加「阅读边界」「免责声明」「制作说明」
6. **禁止伪完成**：不用占位图、假 logo、坏链图；**卡面有乱码/错字就不算完成**，不许「先出着看」
7. **最终视觉检查**：三秒内能找到主判断；文字无溢出、无遮挡、无过小字号、无孤行

## 五、怎么进流程

```json
{"id": "quote-1", "role": "quote-card", "ratio": "1:1", "quality": "low",
 "output": "generated/quote_1.png",
 "prompt": "白底 1080×1080 长读卡，一句话居中偏上：『…』；正文深中性黑 #171717，行高 1.9，"
           "有效宽约 896px；右下角小字署名；无装饰性渐变；avoid gradient; avoid drop shadow; "
           "avoid glassmorphism; avoid logo watermark"}
```

- `quality` 用 **low**（`image_budget.quality_draft`）——金句卡是附加产出，不吃封面档
- CRT 类界面风的卡要带 `--engine crt` 过质检门（见 `examples/image-engines/README.md`）
- 预算纪律照旧：manifest 之外的卡不生成；超预算时金句卡排在内文图之后被砍

## 六、和「长读卡」的区别

- **金句卡**（本文件）＝ 1 个判断，1:1，可转发。轻量
- **长读卡**（ljg 的 `-l` 模具思路）＝ 整段论证纵向排版成超长图。**本仓库暂不做**——
  它必须靠 HTML + 无头浏览器截图，与零依赖冲突；真要长图，走 `references/long-image-layout.md`
