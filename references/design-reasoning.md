# 设计推理层（Design Reasoning）— 艺术感/设计感保障

> 阶段④ 配图前的必做步骤。核心观点：**AI 生图「像 AI 图」的根源不是模型弱，而是没有设计意图**——只有「怎么画」没有「为什么这么画」。没有意图，模型只能平均化风格。

## 何时用

**每次编译四段式 prompt 之前**，先跑一次设计推理（≤60 秒），形成 design_reasoning → 再选变体 → 再编译 prompt。

## 设计推理模板（6 项，逐项作答）

```text
① 用途与渠道: 封面首图(2.35:1) / 分享图(1:1) / 内文配图(16:9) / 金句卡(1:1) — 微信小屏阅读
② 受众与气质: [一句话]（例：安静文艺向读者，渴望被理解的情绪）
③ 视觉系统: [风格引擎名] + [风格在本文的具体落点：如"水彩的湿柔+旧书意象"]
④ 主次层级: 画面第一眼看到什么？第二眼呢？（例：先看到窗与雨，再看留白，最后是纸纹细节）
⑤ 留白决策: 留白是设计决策不是默认——留白在这里传达什么？（例：70% 留白 = 孤独感）
⑥ 方向承诺: 拒绝平均化——明确选一个强方向（保守/平衡/大胆，或给用户多方向选项）
```

## 艺术指导词表（替代模糊风格词）

「高级感/氛围感/有设计感」是模糊词，模型听不懂。用**具体艺术指导词**替代：

| 模糊词 | 具体指导词 |
|---|---|
| 高级感 | editorial（编辑感）/ tactile（触感）/ refined（精炼） |
| 氛围感 | cinematic（电影感）/ atmospheric（氛围化）/ dreamlike（如梦） |
| 有设计感 | graphic（图形感）/ typographic（版面感）/ sculptural（雕塑感） |
| 高级配色 | restrained palette（克制用色）/ tonal harmony（色调和谐） |
| 好看 | balanced composition（平衡构图）/ clear focal point（清晰焦点） |

## 反 AI 味清单（anti-slop，出图 FAIL 后的抢救手册）

### 默认禁止项（初稿就避免）
- 随机渐变雾、无构图逻辑的光效
- 漂浮几何碎片、无意义 HUD 叠层
- 过度镜头光晕（lens flare）
- 处处拥挤的细节（无呼吸感）
- 一图混多种视觉风格

### 抢救动作（视觉复核 FAIL 时按序执行）
1. 重述主体焦点（一句话）
2. 删掉一层背景复杂度
3. 强制空白安全区
4. 收窄到 2-3 个主色
5. 模糊风格词换成艺术指导词

### 太泛（Too Generic）时
- 加更强构图指令（三分法/对角线/负空间）
- 加一个具体纹理/材质线索
- 明确情绪目标
- 引用真实使用场景（「公众号封面」）

### 太满（Too Busy）时
- 减道具数量
- 减背景对比
- 放大主体
- 更干净的负空间

## 迭代原则

一次只改一个变量：方向 / 层级 / 配色 / 光线 / 写实度 / 密度。改多了不知道是哪步起效。

## 构图法则（可选工具，不是定律）

三分法 / 黄金分割 / 对角线 / 负空间 / 中心构图——**构图规则是帮助不是禁锢**。设计推理定了意图后，构图法则是表达意图的工具，可守可破。
