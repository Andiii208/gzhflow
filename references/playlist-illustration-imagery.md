# 歌单/音乐类推文配图：音乐物件意象映射（2026-08-05 用户拍板）

> 背景：歌单总结推文《八年，1301 首》配图连否 6 轮（zine → 喜茶水墨 → 喜茶极简 → 喜茶摄影 → 喜茶插画 → 潦草手账×茶意象），用户点破根因「你非要沿用茶这个意象吗？我觉得它并不是一个很适合我这个推文的意象」。**最终认可方向：潦草手账涂鸦画风 × 音乐物件意象**（黑胶/磁带/耳机/红心/声波）。

## 核心原则

1. **意象从文章主题的「本体」里长出来**：歌单推文 → 听歌的物件（红心=收藏动作、黑胶/磁带=实体唱片时代、耳机=听、声波=歌）。
2. **红心意象最强**：网易云「我喜欢的音乐」= 点红心收藏；1301 首 = 1301 次红心。方大同离世段用「被 scribble 乱线围住的红心」比空茶盏戳心。
3. **不要**茶/器物类隐喻（杯、壶、席），不要其它无关风格的硬套。

## 已验证意象映射（15 prompt 全过质检门 + 用户认可）

| 段落/情绪 | 意象 |

## 四段式 prompt 模板（潦草手账 × 音乐物件）

```text
P1: 16:9 横版 全幅{白纸|牛皮纸}底, 约 80% 留白, {白纸|牛皮纸}纸纹, sketchy 抖动线条与 scribble 乱线, {马克笔笔触|doodle 小涂鸦}, 视觉簇位于中下不贴边，画面顶部与底部边缘各保留纯纸色留白，便于安全裁切
P2: 主体：{黑胶唱片/磁带/耳机/红心/声波线}，潦草铅笔勾勒线条抖动歪斜，{纹路用 scribble 乱线|转轮用马克笔点涂|红心用砖红马克笔涂出}，一处涂改痕迹，{旁边贴胶带|一个手绘箭头}
P3: 无图内文字（不写任何文字）；muted palette with {砖红|旧蓝|焦黄|橄榄绿} marker accents, 铅笔灰线条贯穿
P4: 氛围随性松弛、手账日记感、留白呼吸感；避免精致矢量插画、避免完美平滑线条、避免高饱和、避免渐变紫、避免日系动漫、避免卡通、避免照片质感、避免3d渲染
```

- 白纸 vs 牛皮纸交替用（白纸配旧蓝/砖红，牛皮纸配焦黄/橄榄绿），避免整套图底色雷同。
- 每张图保持「一个主体物件 + 一处涂改/胶带/箭头细节 + 大留白」，不要堆场景。
- 图片说明文字也走音乐意象：「声波弯成了山」「戴着耳机听月亮」「从磁带，到唱片」。

## 风格确认节奏（血泪教训）

1. **先 1 张试水**（封面方向）→ 用户确认 → 再批量 15 张（封面 2 + 内文 13）。
2. 试水通过的 prompt 模板直接复用，只改 P2 意象词，不要每张重编。
3. 批量后统一裁剪：封面 2.35:1（PIL center crop）、分享 1:1、内文 16:9→900×506 jpg。
