# 配图路由方法论（Image Routing）

> 阶段④ 配图层的核心方法论。原则：**先定图源，再定画风；文风路由 → 配图风格 → 引擎。**
> 你的配图风格引擎定义在 `examples/image-engines/`（空白模板 + 示例）。

## 一、图源三问（第一步必做）

配图层第一步不是查风格，是**先定图源**。每个意象块独立决策，允许整篇混用真实图与 AI 插画——真实图管「见证」，AI 插画管「想象」。

1. **本体问**：这个意象指向的东西，现实中存在且读者认得出吗？
   - 是（某软件/某张专辑/某地标/某产品）→ 真实图（网上找）
   - 否（回忆/情绪/比喻/抽象）→ AI 插画
2. **功能问**：这张图要「证明」还是「营造」？
   - 证明（截图/数据/界面/操作）→ 真实图
   - 营造（氛围/情绪/风格统一）→ AI 插画
3. **素材问**：网上有没有现成的高质量合规真实图？
   - 有（官方图/CC0 图库/已验证渠道）→ 用真的
   - 找不到或版权不明 → AI 兜底

一句话原则：**意象本体在现实里 → 真实图；在内心 → AI 图；找得到合规真实图永远优先。**

## 二、风格路由（AI 轨）

按文章文风选配图风格。你的引擎列表在 `examples/image-engines/`，每个引擎 = 一个四件套（色彩/纹理/排版/规避）。

> ⚠️ **总原则：风格是参考，不是限制**——路由只给推荐方向，不强制；编译 prompt 时允许跨风格借用/混搭/偏离，以激发创意为准。质检门（质感/雷区底线）仍生效，风格本身是软的。

## 三、四件套引擎结构（每个风格引擎的定义）

```yaml
# examples/image-engines/<name>.yaml
name: "水彩"
description: "手绘水彩风：纸纹、笔触、晕染"
color:            # 色彩引擎
  base: "暖米色纸系"       # 基底色，占画面比例
  accents: ["鼠尾草绿", "陶土橙", "雾霾蓝"]  # 晕染色
  ink: "深灰暖棕"           # 墨色
  forbidden: ["flat vector", "neon glow", ...]  # 禁用词
texture:          # 纹理引擎
  paper: ["cold-pressed paper", "aged paper"]   # 纸感词
  effects: ["wet-on-wet blooms", "visible brush strokes"]  # 纹理词
typography:       # 排版引擎（可选文字规则）
  default: "无文字"
  max_title: "10字"
layout:           # 规避清单
  hard: ["玻璃拟态", "渐变紫", "霓虹", "3D", ...]   # 命中即 FAIL
  soft: ["high saturation", "gradient", ...]        # 命中即 WARN
```

## 四、四段式 prompt 编译模板

```text
P1 画布与纸感: [比例 16:9/1:1] 全幅[纸色]底, [留白比例]留白, [纸感词]+[纹理词×2]; 主体位置与构图自由, 保持留白呼吸感
P2 主体隐喻: [主题转译的意象]（[锚点类型: 旧照片/剪纸/标本/剪影/晕染物]）, [锚点处理: 边缘渗开/洗淡/纸感/笔触]
P3 文字与色彩: 默认无文字; 仅封面带字时填 [文字, 字体, 位置], [晕染色1]+[晕染色2] 以[湿画法/晕染带/洗淡照片区]存在, [纸缺陷: 轻微溅墨/水痕/纤维]
P4 氛围与规避: [氛围词], avoid [规避词1]; avoid [规避词2]; ...（规避词必须「avoid X」成串）
```

**转译规则（P2 是唯一自由发挥点）**：
- 把抽象主题转成一个可画的具体意象（不是场景堆砌）
- 一个隐喻 > 三个元素；宁缺毋滥
- 例：孤独 → 一扇半开的窗，窗帘被风吹起一角；疲惫 → 桌上一杯凉透的茶
- 连续生成多张图时布局避免雷同（换锚点类型/视觉语法）

## 五、配图规格

| 用途 | 比例 | 说明 |
|---|---|---|
| 封面首图 | 16:9 生成 → 中心裁 2.35:1 ≈ 900×383 | 默认无文字；带字时 ≤10 字、左右 ≥15% 留边 |
| 分享图 | 1:1 | 默认无文字，单一视觉焦点 |
| 内文配图 | 16:9 ≈ 900×506 | 宽幅横构图，prompt 显式锚定横向元素 |
| 金句卡 | 1:1 | 正文原句 ≤20 字，不得编造/改写 |

- 封面安全区：生成时顶部/底部保留纯色留白（便于 2.35:1 中心裁），不是靠裁剪锚点
- 图片统一 .jpg 扩展名，quality 82-85

## 六、质检门

```bash
echo "prompt内容" | python scripts/check_image_prompt.py
```

- FAIL → 改 prompt 直到 PASS；WARN → 尽量消除
- **PASS 才允许调图生后端**

## 七、通用防坑（意象纪律）

- **意象匹配 > 画风**：配图被否的根因往往不是画风，是意象选错了。意象从文章主题的「本体」里长出来（歌单 → 红心/唱片/耳机），不是外部硬套一个「好看但无关」的隐喻
- 任何风格都落到**可识别的人/物/叙事**，抽象隐喻线条不适合公众号配图
- 人物朝向关系必须画得出（「面对面」要用侧面剪影相对，纯背影看不出）
- 一图单一视觉焦点；拼贴图一个意象 = 一张主体照片碎片
- 微文本要么极小要么 textless（长数字串会被当乱码）
- **先 1 张试水再批量**：风格/意象不确定时，先出 1 张给用户确认方向
- 单张连被否 2-3 次后停止猜测，列候选方向让用户选
