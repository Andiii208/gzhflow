## 已确认教训（与 SKILL.md 写作陷阱同步）

1. 素材确认问题（读者定位/标题）≠ 素材先行问题，不能替代
2. 大众感受主题禁编通用场景（食堂/电梯/课间）；连给读者（"你"）预设行为（"你也会发一条"）也是编；共情=直接说破共同感受，无画面直说
3. 共情向砍科普数据（90小时/接近效应/调查百分比），研究背书=知识帖=AI味
4. 旧认可结尾句（"不说也可以"）不可跨文章复用
5. 骨架确认法有效：要写N条 + 明确不写N条（不写清单来自用户历次否定的点名项），用户逐条确认回"对"再动笔
6. "再回去重新问一遍"=回到上一个提问重新问，别跳步
7. **口语毛刺堆砌=伪人味**：满篇「其实/好像/隔三差五/好不容易/也就这样了/吧」被批"过于生活化反而显得很AI"。毛刺≤2-3处；句子主体干净书面
8. **共情文"再深入"两步走**：先加一层机制洞察（时间观功利化），再命题化+文采化。思辨=锋利命题（认识空前便宜朋友空前昂贵/人一旦被安排目的就会把自己收起来），文采=意象+对仗+精准词（时间标好了用途/活动一散人也就散了）

## 最终方向（用户已确认的骨架）

要写：①大学里认识很容易，朋友很难 ②每天见面的人也只是见面，卡在没机会更进一步 ③（补充）学校活动功利化，距离还是大 ④朋友是处出来的，大学里没机会处 ⑤不是你一个人的问题。
不写：具体场景 / 机制分析 / 教人交朋友 / 「不说也可以」「就都通了」类收尾。

## v7 最终稿全文（451字，check_prose 全 0）

```
大学里的朋友，越来越难交。

认识太容易了，加个微信就算。可认识离朋友，差得很远。中间隔着什么，谁也说不清楚，只知道那一步始终没有迈出去，时间一长，也就不太去想了。

每天碰面的人，也只是碰面。会打招呼，会聊两句，仅此而已。更进一步需要一个由头，可大学里，除了上课，谁和谁都没有"一起"的理由。一起上课不算，那只是恰好坐在同一间教室。

大学其实安排了最多的相遇。上课，社团，志愿活动，集体活动，不时就有。可这些相遇都带着用途，上课为了学分，活动为了时长和加分。人一旦被安排了目的，就会把自己收起来。活动一散，人也就散了，谁和谁，还是原来那样。

大学最奇怪的地方，大概就在这里。认识空前地便宜，朋友空前地昂贵。友谊生长的地方，是没有目的的那种待着。两个人不为什么凑在一起，待久了，自然就熟了。可大学里的时间，每一分钟都标好了用途。连闲着都不踏实，总想做点"有意义"的事。而友谊恰恰是最没用的一样东西，换不来学分，进不了简历，只长在那些无用的时间里。这样的时间，在大学里越来越稀有。

朋友是处出来的。可"处"需要大把无目的的时间，而这些时间，都被有用的事占得干干净净。所以不是哪一个人的问题，很多人都这样。

那一步，也许哪天就发生，也许不会。说不上来。

就到这里，下次见。

——Andiii碎碎念
```
