## Phase 1：采集文章

使用 wechatDownload（D:\tools\wechatDownload）批量下载目标公众号文章。

**流程：**
1. **找 URL**：微信生态封闭，开放网络搜不到公开链接。需用户从手机微信分享文章链接。
2. **远程 MCP 单篇下载**：`mcp__wechat_download_mcp__wechat(url, config={"MD":true})` — 远程接口可直接下载单篇，适合先用浏览器确认文章内容和来源。
3. **本地桌面端批量下载**：
   - 运行桌面端 → 粘贴 URL → 获取公众号 ID
   - 电脑微信打开链接 → 获取密钥
   - 批量下载 → 选择 MD 格式
4. 复制到 `raw_articles/group_X/公众号名/`

**已成功案例：**
- 槽边往事 — 7篇（从博客站点 hecaitou.com 直接复制）
- MorningRocks — 11篇（桌面端批量下载）
- 新世相 / 我要WhatYouNeed / 杂乱无章 / L先生说 — 各1篇（远程 MCP 单篇下载，通过浏览器确认来源）

**找链接的技巧：**
- 播客节目 show notes 中常出现公众号文章链接（如 Apple Podcasts）
- Google 搜索 `mp.weixin.qq.com/s` + 公众号名 + 文章关键词 偶有命中
- 最可靠的方式：用户在手机微信打开文章 → 复制链接

## Phase 2：逐篇 10 维度分析

每篇文章填写一张分析卡，使用 10 维模板：

1. **标题分析** — 句式、长度、技巧、公式
2. **开头分析** — 方式、节奏、人称、与读者关系
3. **语气与人格感** — 定位、基调、"你"/"我"频率、自我暴露
4. **段落节奏** — 平均长度、空行、单句成段、蓄力释放
5. **内容结构** — 类型、分段、推进方式
6. **结尾分析** — 方式、长度、互动引导
7. **配图与排版** — 风格、数量、图文关系
8. **选题特征** — 来源、颗粒度、读者距离
9. **典型句子摘录** — 3-5句代表性句子
10. **综合印象** — 核心特征 + 一句话模仿指南

### 并行分析技巧

用 `delegate_task` 子 agent 并行分析多篇文章，效率远高于逐个手动填写：

**拆分策略（18篇案例）：**
- 每个 agent 负责 5-7 篇文章
- 按公众号拆分：槽边往事 1个 agent，MorningRocks 分 2个 agent
- 每个 agent 需传：分析模板全文 + 文章路径列表 + 输出目录

**实践验证：** 3 个 agent 并行分析 18 篇文章，约 5-10 分钟完成全部分析卡产出。

## Phase 3：组内综合

汇总同组所有分析卡，提取：
- **共性模式**：标题、开头、语气、段落、结构、选题的共通规律
- **差异化特征**：每个号独特的技巧
- **可借鉴元素**：哪些技巧可以融合进"Andiii碎碎念"

## Phase 4：风格签名

生成一份完整的个人写作风格定义文档，包含：
- 定位（我是谁，这个号的调性）
- 语气
- 选题边界（✅ 做的 / ❌ 不做的）
- 标题风格
- 开头方式
- 段落节奏
- 文章结构
- 结尾方式
- 配图风格
- 排版规范

## Phase 5：Hermes Skill

基于风格签名创建可被 Hermes 调用的 SKILL.md，包含：
- 风格路由表（根据话题自动匹配不同风格）
- 写作步骤
- 配图 + 发布流程

## Phase 6：验证

用 Skill 写一篇测试文章 → 发布到公众号草稿箱 → 用户审核
