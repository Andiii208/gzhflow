# 文风分析卡（10 维模板）

> 逐篇分析公众号文章时使用。每篇文章一张分析卡。

## 元信息
- 公众号：
- 文章标题：
- 发布日期：
- 文章链接：
- 字数：

## 1. 标题分析
- 标题句式：（陈述句/疑问句/祈使句/省略句/名词短语）
- 标题长度：__字
- 标题技巧：（数字/悬念/共鸣/反常识/场景感/情绪词/无技巧）
- 标题公式提炼：___

## 2. 开头分析
- 开头方式：（场景切入 / 引用 / 提问 / 直接陈述 / 故事开头 / 金句开头）
- 开头 100 字节奏：（短句密集 / 长句舒缓 / 长短交错）
- 第一人称使用：（有/无）
- 开头和读者的关系：（你在对我说话 / 我在自言自语 / 我在讲故事）

## 3. 语气与人格感
- 语气定位：（同龄朋友 / 前辈 / 孤独者 / 观察者 / 其他）
- 情绪基调：（温柔/犀利/幽默/忧伤/平静/慵懒）
- 使用"你"的频率：（高/中/低）
- 使用"我"的频率：（高/中/低）
- 自我暴露程度：（高/中/低——是否分享自己的脆弱/困惑/糗事）

## 4. 段落节奏
- 段落平均长度：__行
- 段落间常留空行：（是/否）
- 关键句单句成段：（频繁/偶尔/从不）
- 是否有蓄力→释放节奏：（是/否）

## 5. 内容结构
- 文章类型：（纯感受/故事+感悟/层层递进/碎片拼接/对话体）
- 是否有明确分段标题：（是/否）
- 推进方式：（一件事→一个感悟 / 多件事→一个主题 / 纯情绪流动）

## 6. 结尾分析
- 结尾方式：（金句收尾/问题留给读者/情感升华/平淡收束/引用）
- 结尾长度：__行
- 结尾有互动引导：（是/否）

## 7. 配图与排版
- 配图风格：（摄影/插画/纯文字/极简/拼贴）
- 配图数量：__张
- 配图和文字的关系：（独立存在 / 承载文案 / 装饰）

## 8. 选题特征
- 选题来源：（个人经历/观察他人/媒体事件/阅读所得/抽象感受）
- 选题颗粒度：（很小的事 / 中等感悟 / 大的话题）
- 选题和读者的距离：（很近/中等/远）

## 9. 典型句子摘录
- 摘 3-5 句最能代表该号风格的句子
- 标注为什么这句有代表性

## 10. 综合印象
- 这个号最核心的一个特征是什么？
- 如果用一句话教新手模仿这个号，你会说什么？
